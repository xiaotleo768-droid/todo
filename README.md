# 随手事项本（本地版）

手机上随手记待办和灵感，做完一键完成并记下时间，可以按时间段导出 Excel 复盘。

- 数据只保存在手机浏览器里，不上传到任何服务器，GitHub 上只放程序本身
- 打开过一次以后，没有网络也能用
- 支持语音输入、分类管理、备份和恢复

## 文件说明

| 文件 | 作用 |
|---|---|
| index.html | 应用本体 |
| manifest.webmanifest | 让手机把它当作应用安装（图标、名称、全屏） |
| sw.js | 离线缓存，没网也能打开 |
| icon-192.png / icon-512.png / apple-touch-icon.png | 桌面图标 |

## 一、放到 GitHub Pages（大约 5 分钟）

1. 登录 GitHub，点右上角「+」→「New repository」。
2. Repository name 填 `todo`（也可以用别的英文名），选 **Public**，点「Create repository」。
   免费账号的 GitHub Pages 只支持公开仓库。公开的只是程序代码，你的事项数据在手机里，别人看不到。
3. 在新仓库页面点「uploading an existing file」，把压缩包里的 **所有文件**（不是文件夹）拖进去，点「Commit changes」。
4. 进入仓库的「Settings」→ 左侧「Pages」→ Source 选「Deploy from a branch」，Branch 选 `main`、文件夹选 `/ (root)`，点「Save」。
5. 等 1～2 分钟刷新这个页面，顶部会显示网址，形如 `https://你的用户名.github.io/todo/`。

## 二、添加到手机桌面

**安卓（Chrome / Edge）**：打开上面的网址 → 右上角菜单 →「添加到主屏幕」或「安装应用」。
华为、小米、OPPO、vivo 自带浏览器也有「添加到桌面」，如果没反应，去手机「设置 → 应用 → 浏览器 → 权限」里打开「桌面快捷方式」。
安卓上长按桌面图标，还能看到「记灵感」「记工作」两个快捷入口。

**苹果（必须用 Safari）**：打开网址 → 底部「分享」按钮 →「添加到主屏幕」。

以后都从桌面图标打开。注意：从图标打开和从浏览器打开，数据可能是分开的，固定用一种方式就好。

## 三、语音输入

- 点输入框右边的麦克风，可以直接说话转文字（苹果 Safari 一般可用）。
- 国内安卓手机的浏览器大多不支持网页里直接识别语音，点麦克风会提示你改用 **键盘上的语音键**：点输入框，再点讯飞、搜狗、百度、微信输入法或系统键盘上的麦克风说话，效果一样。

## 四、备份很重要

数据只存在这台手机的这个浏览器里。下面这些情况都会丢数据：清理浏览器数据、卸载浏览器、换手机。

- 在「统计导出」页点「备份到文件」，会保存一个 `.json` 文件，可以发到微信文件传输助手或存到网盘。
- 换手机或数据丢了：打开应用 →「从备份恢复」→ 选这个文件。导入是合并，不会产生重复记录。
- 记录超过 5 条却从没备份，或者 14 天没备份，待办页会提醒你。

苹果和安卓两台手机的数据互不相通。如果想把一台手机的记录搬到另一台，用备份文件导过去就行。

## 五、以后更新程序

把新的文件上传到同一个仓库覆盖旧文件即可，数据不受影响。
如果改了 `index.html`，同时把 `sw.js` 里的 `sxb-v1` 改成 `sxb-v2`（以此类推），手机下次打开时会自动换成新版本。
